How do distributed transactions work in Azure Cosmos DB? In public preview, distributed transactions let you commit writes across partition keys, containers, and databases within a single Azure Cosmos DB account. Unlike a transactional batch, which is limited to one logical partition, a distributed transaction uses two-phase commit to keep writes atomic: either every write succeeds or none takes effect.
