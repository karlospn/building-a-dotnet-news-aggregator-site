A trace records a run that already happened, so it can't tell you what the agent would have done if a tool had behaved correctly. LangGraph Studio can. In this lesson we reproduce the LangSlice out-of-stock bug, edit the add_pizza_to_order result at its checkpoint to the rejection it should have returned, and fork the run from there. With that one value changed, the agent tells the customer pineapple is out of stock.…
