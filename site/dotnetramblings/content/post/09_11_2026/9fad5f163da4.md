In a monorepo, every commit or pull request can trigger a full rebuild and test of all projects even when only one small piece changed. Meziantou.DeltaBuild is a .NET CLI tool that solves this problem by analyzing git changes and the MSBuild dependency graph to produce a filtered solution or build file that contains only the affected projects.
